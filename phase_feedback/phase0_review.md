# Phase 0 Review Feedback

## Summary
- High severity: 2 findings
- Medium severity: 2 findings
- Low severity: 1 finding

## Findings
1. **High – Preflight probes depend on local LXD exec instead of the advertised MicroCeph endpoints.** The probe helpers shell into targets with `lxc exec`, so the controller must run on the same LXD host as the cluster nodes. That breaks the stated requirement of validating reachable MicroCeph endpoints and prevents running against standard physical or VM deployments. Evidence: [src/chopsticks/probes/cluster_health.py](src/chopsticks/probes/cluster_health.py#L12-L123), [src/chopsticks/probes/network.py](src/chopsticks/probes/network.py#L13-L81), [src/chopsticks/probes/resources.py](src/chopsticks/probes/resources.py#L13-L159). *Recommendation:* switch to the SSH transport that Phase 0 assumes, and make the command wrappers configurable so they succeed when the controller only has network reachability.
2. **High – Integration tests bake in a developer-specific working directory.** Each subprocess call sets `cwd` to `/home/utkarsh.bhatt@canonical.com/projects/chopsticks`, so these tests immediately fail on any other machine. Evidence: [tests/integration/test_preflight_integration.py](tests/integration/test_preflight_integration.py#L35-L72). *Recommendation:* derive the project root dynamically (e.g., `Path(__file__).resolve().parents[2]`) or drop the override altogether.
3. **Medium – Integration tests require live LXD VMs and `uv` but have no skip guard.** The tests marked `integration` still run for anyone invoking plain `pytest`, and they invoke `uv` plus LXD-managed hosts that are unlikely to exist in CI. Evidence: [tests/integration/test_preflight_integration.py](tests/integration/test_preflight_integration.py#L31-L77). *Recommendation:* add `pytest.importorskip` checks for `uv`, verify hosts before running, or gate the tests behind a marker that defaults to skipped without an explicit opt-in.
4. **Medium – Network probe only proves LXD exec works, not network reachability.** Returning “reachable” after `lxc exec host -- echo ping` merely confirms the local hypervisor can spawn a shell; it does not validate controller↔node networking as required. Evidence: [src/chopsticks/probes/network.py](src/chopsticks/probes/network.py#L13-L58). *Recommendation:* perform an actual network operation (e.g., ICMP, TCP handshake, or `microceph` API call) over the target management network.
5. **Low – Report writer fails if the output directory is missing.** `save_to_file` writes directly to `Path(filepath)` without creating parents, so `--output preflight/reports/phase0.yaml` raises `FileNotFoundError`. Evidence: [src/chopsticks/utils/report.py](src/chopsticks/utils/report.py#L54-L72). *Recommendation:* call `Path(filepath).parent.mkdir(parents=True, exist_ok=True)` before writing.
